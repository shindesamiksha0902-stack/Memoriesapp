# memories PWA

## Run locally
Use any static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
Upload to Vercel or any HTTPS static host.

## Notes
- `public/icons/icon-192.png` and `public/icons/icon-512-final.png` are included.
- The app already registers `sw.js` and has a manifest.
